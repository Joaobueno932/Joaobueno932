# Publicação do perfil

1. Abra o repositório `Joaobueno932/Joaobueno932`.
2. Envie `README.md`, a pasta `assets/` e `.github/workflows/snake.yml` preservando os caminhos.
3. No GitHub Actions, execute o workflow da animação Snake. Verifique as permissões de escrita do workflow se necessário.
4. Verifique o perfil nos modos claro e escuro. O cabeçalho e o painel são SVGs locais e não dependem de APIs externas.
5. As três métricas exibidas são valores fixos declarados pelo autor; atualize `assets/metricas.svg` caso mudem.

O gráfico Snake usa apenas os dados acessíveis ao gerador. Seus totais podem divergir dos valores declarados.
